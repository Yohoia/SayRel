## 边界与仍未覆盖

- 现有Sayrel没有老用户完整洞察/热图/云端学习数据，仍使用新用户首页；不生成伪数据或声称个性化完成。
- 翻译、云同步、历史重试/下载录音、词典原位编辑仍无本轮可复用的完整后端接线；相关控件明确不可用或不展示。
- 原版的“从不保存历史”不映射到Sayrel的`historyRetentionDays=0`，因为Sayrel的0表示永久。该选项未提供。
- 原版历史隐私说明包含“零数据保留”保证，Sayrel可配置第三方语音/模型服务，因此只陈述本地历史存储事实。
- 单词与CSV UI操作使用现有接口；没有伪装原版批量API的事务原子性。
- 历史列表沿用已有200条查询上限；完整虚拟滚动/分页和原版回答查看器不在此次Hub组件补齐范围。
- 本轮`npm run typecheck`通过。预览服务启动受执行环境限制，需由主任务完成运行时截图和交互验收，不能将静态核对描述为全量1:1验收。
