# 实时字幕与空语音退出

日期：2026-10-25。

## 交互选择

用户在输入时只需瞥见最新识别内容，不应为了关闭空语音提示而中断输入。沿用现有灰白底、蓝字、MiSans 和悬浮条尺寸，不增加操作按钮。

初版使用双行字幕和处理提示，用户明确否定后已替换：当前为 15px 单行、无边框、无整块背景的字幕。新增识别文字把前文平滑推向左侧，两端以渐隐遮罩和局部模糊软化边缘；不循环播放旧内容。录音中显示呼吸光标，停止后保留识别文本但不追加“正在处理…”等文字；完成、取消、失败或换会话时清空。不添加假打字延迟，不把识别草稿当成最终润写结果。

首次出现时先完成文字宽度测量，再在悬浮条正上方居中淡入；首次定位不播放位移动画。后续文字增长才启用平滑左移，超出可见宽度后跟随末尾。界面回归采样首次可见的八帧，验证中心没有横向漂移，并检查入场动画只改变透明度。

字幕不接收鼠标事件、不抢焦点，翻译等模式下避开模式面板；360px 窄窗口保持边距。减少动态效果偏好关闭字幕入场、横向移动和光标动画。屏幕阅读器不逐次播报高速更新的草稿。

设置 → 音频提供“显示实时转写”（`showLiveTranscript`），默认开启，保存后立即影响悬浮条，重新打开仍保留。关闭仅隐藏字幕；实时 ASR、后续润写、录音停止方式和自动写入均不变。重新开启会显示当前会话最新的识别结果，不必重录。设置面板和悬浮条共用同一个设置状态，避免初始化读回覆盖较新的开关值。

普通听写的原生粘贴无法读回确认时，不再自动打开结果卡。它保留 `delivery=unverified` 与原校验记录，不伪报写入成功，也不重贴；明确派发异常、安全输入阻断等情况仍保留恢复入口。提问及用户主动重润写的结果卡不受影响。

## 空语音边界

成功返回空字符串或空白字符的 ASR 是正常空结果，不是服务失败。它直接结束会话并返回空闲，不润写、不执行指令、不写入目标应用、不启动词典学习、不显示结果卡或错误提示。已按隐私设置生成的历史和录音继续保留，历史标记为完成并记录 `asr.kind=empty`，不伪造正文，也不计入活跃天数或听写用量。

停止时尚未收到 PCM 的原有路径也安静退出。网络、认证、超时、麦克风故障仍是错误，不能仅因错误消息包含 silence 或 empty 就静默处理。没有新增依赖音量阈值的本地静音判断，因此不能保证过滤语音模型的幻觉文字。

Typeless 参考来自本地恢复的 2.8.3 客户端 `reference/typeless/extracted/app-2.8.3/dist/renderer/static/js/juYOhWy9.mjs`：字符偏移 137400、137652、138239 附近仅在整理结果非空时派发；153706 附近处理短音频空完成；182354 附近返回空闲。这些是静态客户端证据，不代表已实测当前 Typeless 服务端的静音识别策略。

## 验证

- 新增 UI 回归在修改前失败，原界面没有字幕滚动组件；修改后验证最新内容、改口替换、旧会话隔离、处理中保留、空闲清空、翻译避让和窄窗口边距。
- 空 ASR 回归在修改前失败，状态为 error 而非 idle；无读回自动弹卡回归在修改前失败，交付状态为 card 而非 unverified；修改后录音恢复脚本共 65 项通过。
- `npm run typecheck`、`npm run verify:dictation`、`npm run verify:voice`、`npm run verify:activity` 通过。真实 SQLite 回归验证空语音不增加统计，旧版空白或异常元数据仍兼容。
- `npm run verify:settings` 与设置界面回归覆盖新开关的默认值、保存、广播、非法值拒绝、恢复默认和保存失败重试。悬浮条回归覆盖录音中即时隐藏、隐藏期间继续接收结果、重新开启显示最新文字及重新加载后保留关闭状态。
- `npm run verify:floating` 通过，随后其 Electron 交互脚本连续运行三次通过。截图位于 `docs/ui-evidence/floating-interactions/live-transcript-*.png`，通过真实界面代码与隔离离线 IPC fixture 生成；没有调用供应商或使用私人录音。
- 初版经过一轮独立视觉评审；本次以用户明确提出的单行、左右模糊、无边框要求取代初版方向。没有修改用户已有的设计规范文件。

## 开发版生效核对

本次用户仍看到旧的未识别语音异常。核对发现源码已修改，但实际启动的 `out/main/index.js` 仍包含旧异常，原 `electron-vite dev` 不监听主进程变更。开发命令已改成 `electron-vite dev --watch`。停止旧项目进程后重新启动，检查生成产物不再包含该异常，并包含新的静默未确认交付策略，原生模块均加载成功。

复跑：`npm run verify:floating`；`npm run verify:dictation`。这些检查不替代实体键盘、真实麦克风和不同目标应用的现场验收。
