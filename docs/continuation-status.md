## 当前实现

- Fn 口述、Fn+Shift 翻译、Fn+Space 问答；迁移旧默认绑定。默认轻按开始、再按结束；按住超过 600ms 停录并提示轻按。保留自定义 hold 模式。
- Swift 监听器锁定同一物理手势，Fn 后追加 Shift/Space 升级当前模式，不启动第二个会话；释放顺序、重复按键、无关 flags、tap reset 均有回放断言。已生成 arm64/x86_64 通用 KeyboardHelper 动态库。
- 原生监听不可用时使用 Electron 替代组合键；辅助功能权限恢复后重新启动原生监听并撤销替代注册。设置修改同步主界面和悬浮条标签。
- 录音由 main 管理 sessionId，starting 驱动 renderer 开麦，结束等待 worklet/fallback 尾包和 chunk IPC，再等待 stopped ACK。取消使迟到开麦、PCM 和供应商结果失效；清理音轨并恢复原先未静音的系统声音。
- 悬浮条保持原版几何、波形、处理中进度、蓝色翻译光晕与倒计时。鼠标开始进入免手持模式，提供完成和取消按钮；错误点击重试失败音频；长按显示提示。提示快捷键随模式变化。
- Fn+Shift 调用独立翻译动作、Fn+Space 调用问答动作，复用已配置的模型连接；未更换现有口述转写/润写实现。问答显示结果卡与选中文字。
- 历史支持筛选、分页、录音下载、重试、回答查看、从不保存选项；词典支持编辑。历史重试更新原记录并显示结果卡，不向当前焦点窗口插字。重试失败会传回页面；历史变化触发页面刷新。
- 首次启动实际打开权限/麦克风/快捷键引导窗口，修复此前没有接收方的 onboarding 消息。

参考依据：`reference/deob/renderer/DFvLNtQv/deobfuscated.js` 的 LONG_PRESS_MS（5863）、awaiting_long_press_or_tap/long_pressing（6733–6803）、悬浮条组件（7780 以后），以及先前 UI 对齐记录所列资源。静态源码是行为/样式依据，不是像素一致证明。

## 尚未完成的验收

- 新版运行时截图及真实键盘→麦克风→供应商→目标输入框验收尚未完成。不得据此记录声称“全量 1:1 复刻已验收”。
- 本地 UI 服务在沙箱内被拒绝监听。申请仅监听 127.0.0.1:4173 的服务时，自动审批返回 503（审批模型无可用渠道）；不是安全拒绝。
- 已准备不监听端口的离线 fixture 构建与 Electron 截图脚本。沙箱内 Electron 退出 SIGABRT；提升权限的审批也返回同一 503，未执行。本轮没有生成的新截图，旧截图不代表本轮结果。
- 可在可用的本机终端运行 `npm run verify:ui`，输出到 `docs/ui-evidence/continuation/`。脚本使用临时 Electron profile、阻止 HTTP(S)、只加载 fixture，不启动真实录音服务。脚本已准备，但完整运行结果待验。
- 真机验收需分别轻按 Fn、Fn+Shift、Fn+Space；验证松开后继续录音、再次轻按完成、长按提示、Esc 取消、点击浮条完成、改变绑定即时生效。转写/翻译/问答需要用户现有可用供应商配置与系统权限。
