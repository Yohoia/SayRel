# 首页热力图与 Hermes 字标

2026-10-21。用户要求首页右侧以参考图的热力图替换星盘；随后明确保留 Hermes 字体与配色，删除热力图的背景。

当前实现：Sayrel 符号搭配本地 Rules Gothic Condensed 字标，28px 符号、36px 字号与行高。首页保留两行标题和快捷键，右侧改为三项统计与 7×26 网格，直接置于纸灰页面，没有天空背景、白色面板或阴影。统计数字也使用 Rules，正文沿用 Hermes 参考中的 Inter，所有蓝色色阶来自共享 `--accent`。

桌面采用左右分栏；900px 以下将热力图置于下方；680px 以下依次排列标题、快捷键、统计与网格。保留原有导航、快捷键高亮与应用入口，新增模块沿用首页入场动效；方格支持悬停、聚焦与方向键移动，遵循减少动态效果设置。

统计来自保留的已完成录音，按本机日期汇总。活跃天数、当前连续天数、最长连续天数使用全部保留记录；网格与录音次数显示最近26周。当前连续天数允许今天尚未使用但昨天活跃。未来日期留空。读取失败可重试，空记录显示空网格；后台刷新保留当前内容与焦点。

验证通过：

- `npm run typecheck`、`npm run verify:activity`。后者执行真实 SQLite 与 IPC handler，覆盖超过500条记录、本地午夜、夏令时、闰日、连续天数、未来日期与失败录音排除。
- 首页交互连续通过三轮，最后的文字与时间范围调整另行重跑通过：语言与快捷键、空状态、失败重试、键盘按周查看、无背景、两行标题、600–2560px窗口适配与减少动态效果。
- 中文切换与重载保留、共享字标在设置/引导/回答卡中的应用、历史保留确认流程通过。
- 使用项目现有 Electron 离线截图流程，网络关闭，临时配置；不访问物理麦克风和真实服务。

独立视觉评审按 `oil-ui-pro` 存量界面流程完成一轮，不打分。修正了“最近26周”范围可能涵盖全部统计的歧义，以及月份、星期、图例字号不足的问题；三项辅助标签统一13px。保留既有定位眉标、虚线快捷键和应用入口，它们属于此前选定方向；删除重复的网格说明与统计脚注，以统计范围标签和实际次数替代。
