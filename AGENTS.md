# Agent Configuration

This document configures how AI agents work with the OffKey codebase.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repository (`Yohoia/OffKey`). Skills use the `gh` CLI to create, read, and update issues. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout: one `GLOSSARY.md` at the repo root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
